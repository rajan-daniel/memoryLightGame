## 🟡 Memory Light Game (Simon Says Clone) (React, JavaScript, HTML & CSS Project)

### 📌 Preview  
A Simon Says–style memory game built in React where players must repeat progressively longer light sequences. The game includes multiple modes, audio-visual feedback, and a full state-driven game engine with strict mode and round progression.

---

### 📖 About the Project  
The **Memory Light Game** is a fully interactive Simon Says clone built using React, designed around a custom state-driven game engine. The player must memorize and reproduce an increasing sequence of flashing lights generated by the system.

The game starts when power is enabled, generating a random sequence of up to 20 steps. Each round, the game plays back the sequence using timed animations and sound effects, then switches to input mode where the player must replicate it exactly.

A major part of this project was building a **custom game state machine using React hooks**, where different states control the entire flow of the game:
- `on` / `off` (power state)  
- `playing` (sequence playback)  
- `input` (player interaction)  
- `checking` (validation phase)  
- `new-round` (progression system)  

The game also includes a **Strict Mode**, which resets the game completely on any mistake, increasing difficulty.

Audio feedback and button flashing are tightly synchronized using `setTimeout`, DOM class manipulation, and dynamically generated audio instances. The system ensures player input is locked during playback to prevent invalid interactions.

### 📍 The Process  
This project was built in multiple iterative stages, with each commit representing a clear step in developing the final game.

I started by setting up the **React boilerplate and project structure**, then reorganized the files and moved everything into a cleaner root setup. After that, I began experimenting with storing the entire game state in a single structured state object to better manage the game flow.

From there, I focused on building the **core game engine logic**, including sequence generation, gameplay loops, and input validation. This evolved through multiple iterations as I refined how the game tracks player input and compares it against the generated pattern.

Once the core mechanics were stable, I improved the system by fixing state mutation issues and ensuring React state was handled correctly and predictably.

After the logic was solid, I moved into enhancing the **user experience layer**, adding:
- Button flash animations during sequence playback  
- Sound effects for user interactions  
- Visual feedback for button presses  

I then completed the full **sequence playback animation system**, ensuring smooth timing between each step of the pattern.

The final stages focused on polishing the project:
- Added favicon and refined overall styling  
- Completed full UI styling and visual consistency  
- Improved layout and responsiveness  
- Set up **GitHub Pages deployment** for hosting  

Each step built on the previous one, gradually turning a simple React setup into a fully functional Simon Says memory game with sound, animation, and complete gameplay flow.
